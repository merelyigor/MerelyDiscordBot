# Конфігурація

У `src/config.ts` перевіряються обов'язкові змінні середовища. Runtime отримує їх з Docker Compose, а файли середовища для локального й production профілів розташовані в `../docker/.env.local` та `../docker/.env.prod` від кореня репозиторію. `../docker/.env` є похідним файлом.

Обов'язкові змінні: `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`, `OFFICE_TEXT_CHANNEL_ID`, `OFFICE_VOICE_CHANNEL_ID`, `DB_HOST`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`. Compose задає `DB_HOST=infra-mariadb-database`, якщо змінну не перевизначено. Опційні: `DISCORD_GUILD_ID`, `DB_PORT` (за замовчуванням `3306`), `BOT_HEALTH_FILE`, `DAILY_QUOTE_CHANNEL_ID`, `DAILY_QUOTE_HOUR` (за замовчуванням `9`).

Джарвіс вмикається лише через ENV: `JARVIS_ENABLED` (`true`/`false`, за замовчуванням `false`), `OLLAMA_API_KEY` (обов'язковий основний секрет; відсутній або порожній вимикає Джарвіса, бот працює далі), `OLLAMA_API_KEY_2.._5` (резервні ключі для ротації лімітів, додаються лише за наявності основного ключа; порожні ігноруються), `OLLAMA_BASE_URL` (лише HTTPS, за замовчуванням `https://ollama.com`), `JARVIS_MODEL` (`gemma4:31b`), `JARVIS_FALLBACK_MODEL` (`gpt-oss:120b`), `JARVIS_WEB_SEARCH` (`true`), `JARVIS_TIMEOUT_SECONDS` (`90`), `JARVIS_MAX_TOOL_ROUNDS` (`4`), `JARVIS_USER_COOLDOWN_SECONDS` (`5`), `JARVIS_USER_DAILY_LIMIT` (`0` — без ліміту), `JARVIS_MAX_CONCURRENT` (`3`), `JARVIS_CHANNEL_IDS` (ID каналів через кому; порожньо — усі канали), `JARVIS_MEMORY_MESSAGES` (спільне вікно: останні N повідомлень усіх юзерів, `1000`), `JARVIS_MEMORY_MAX_TOKENS` (бюджет історії в токенах, `110000`; всередині перераховується в символи ~3 на токен), `JARVIS_MEMORY_TTL_HOURS` (життя памʼяті без звернень, `72` — тримає між днями). Памʼять у RAM, скидається рестартом. `MUSIC_CHANNEL_ID` (канал для `m!play`, дефолт — `#🎶music` сервера), `GIPHY_API_KEY` (ключ пошуку гіфок Giphy; порожньо — інструмент гіфок недоступний і Джарвіс дає посилання на Giphy замість вкладення), `GOOGLE_API_KEY` + `GOOGLE_CSE_ID` (пошук картинок Google; порожньо — фото шукаються лише у Wikipedia). Значення задаються в `../docker/.env.local` і `../docker/.env.prod`; у цьому публічному репозиторії лише назви й несекретні дефолти.

Секрети й значення production ENV не виводити, не логувати й не комітити. `.env` вручну не редагувати: джерела конфігурації належать інфраструктурі.
